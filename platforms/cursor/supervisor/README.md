# Supervisor for Cursor

Native Cursor plugin adapter. It bundles the universal Supervisor Skill, 27 custom subagents, an always-on rule, and a bounded `stop` follow-up review gate.

For local development, copy or symlink this folder to `~/.cursor/plugins/local/supervisor`, then restart Cursor or reload the window.

Once published to the Cursor Marketplace, install with `/add-plugin supervisor`.
